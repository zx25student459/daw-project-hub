DAW Project Hub

Espacio de trabajo para el desarrollo de proyectos web.

Sobre el proyecto

Este proyecto surge con el objetivo de afianzar el uso de herramientas profesionales en el desarrollo de software.

A través de un flujo estructurado de control de versiones con Git, se aprende a registrar cambios de manera limpia y trazable.

La integración con plataformas remotas como GitHub facilita la colaboración y la entrega continua de aplicaciones.
